    This method creates a new filter for a specific user in the Wildduck API. It requires the user's ID as a path parameter and a filter data object in the request body.

    Parameters

    • user: string

      The user's ID. (Example: "507f1f77bcf86cd799439011")

    • filterData: {

              from?: string;

              text?: string;
              to?: string;
          };
          sess?: string;
      }

      The filter data for the new filter.

      • action: {
            delete?: boolean;
            flag?: boolean;
            mailbox?: string;
            seen?: boolean;
            spam?: boolean;
            targets?: string[];
        }

        Action to take with a matching message.

        • Optionaldelete?: boolean

          If true, do not store matching messages.

        • Optionalflag?: boolean

          If true, mark matching messages as Flagged.

        • Optionalmailbox?: string

          Mailbox ID to store matching messages.

        • Optionalseen?: boolean

          If true, mark matching messages as Seen.

        • Optionalspam?: boolean

          If true, store matching messages to the Junk Mail folder.

        • Optionaltargets?: string[]

          An array of forwarding targets (email addresses, relay URLs, or POST URLs).

      • Optionaldisabled?: boolean

        If true, this filter is ignored.

      • Optionalip?: string

        IP address for the logs.

      • OptionalmetaData?: any

        Optional metadata, must be an object or JSON formatted string.

            size?: number;
            subject?: string;
            text?: string;
            to?: string;
        }

        Rules that a message must match.

        • Optionalfrom?: string

          Partial match for the From: header (case insensitive).

        • Optionalha?: boolean

          Indicates whether a message must have an attachment.

        • OptionallistId?: string

          Partial match for the List-ID: header (case insensitive).

        • Optionalsize?: number

          Message size in bytes. A positive value means the message must be larger; a negative value means it must be smaller than the absolute value.

        • Optionalsubject?: string

          Partial match for the Subject: header (case insensitive).

        • Optionaltext?: string

          Fulltext search against message text.

        • Optionalto?: string

          Partial match for the To:/Cc: headers (case insensitive).

      • Optionalsess?: string

        Session identifier for the logs.

  • Delete a Filter.

    This method deletes a specific filter for a user from the Wildduck API. It requires both the user's ID and the filter's unique ID as path parameters. Optional query parameters for logging, such as session identifier and IP address, can also be provided.

    Parameters

    • user: string

      The user's ID. (Example: "507f1f77bcf86cd799439011")

    • filter: string

      The unique ID of the filter to be deleted.

    • Optionalparams: { ip?: string; sess?: string }

      Optional query parameters for logging.

      • Optionalip?: string

        IP address for the logs.

      • Optionalsess?: string

        Session identifier for the logs.

    Returns Promise<{ success: boolean }>

    A promise that resolves to the response of the filter deletion.

    Example

    // Delete a filter for a user
    const deleteResponse = await filters.deleteFilter("507f1f77bcf86cd799439011", "filter123", {
      sess: "session123",
      ip: "192.168.1.1",
    });
